# Architecture électronique

Ce document présente les différents composants pouvant être necessaire à la conception d'un robot suiveur de ligne.

## Liste provisoire des composants inclus dans le kit

- Batterie
- Carte d'alimentation
- Carte controleur de moteurs
- 2x moteurs DC
- Capteur de ligne
- Carte microcontroleur basé sur esp32s3

:::note
Ces diagrammes sont donnés à titre d'exemple et ne sont pas les seules facon de concevoir son robot
:::
