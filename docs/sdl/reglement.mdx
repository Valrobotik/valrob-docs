# Règlement & inscriptions

Le concours suiveur de ligne 2026-2027 aura lieu début mars (probablement le jeudi 11 mars).

## Le règlement

Le règlement complet est disponible en PDF :

**[Télécharger le règlement (PDF)](/files/reglement-suiveur-de-ligne-26-27.pdf)**

## S'inscrire

Les inscriptions se font via ce formulaire :

**[Formulaire d'inscription](https://forms.gle/xB1LemeCphVHiryu5)**

Il n'y a pas de date limite pour l'instant.

## En bref

- **Équipes** : 3 personnes maximum (des exceptions restent possibles).
- **Budget** : 100 € pour tout le monde, dont on déduit le matériel fourni par l'asso (la batterie et l'alim, ou la batterie et toute l'électronique si vous prenez la base électronique complète).
- **Pas encore d'équipe ?** Rendez-vous jeudi 19 novembre à 14h au local pour rencontrer les autres personnes dans le même cas.

:::note
Le budget et les modalités ne sont pas encore définitifs, on vous tiendra au courant.
:::
